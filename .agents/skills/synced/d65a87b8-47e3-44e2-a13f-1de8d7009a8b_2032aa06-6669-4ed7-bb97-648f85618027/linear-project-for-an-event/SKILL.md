Create a new Linear event project for dltHub using the following details:

- Event name: [e.g. "PyData Berlin 2026"]
- Event date: [YYYY-MM-DD]
- City: [e.g. "Berlin"]
- Lead: [name or email, e.g. "steffi@dlthub.com"]
- Priority: [High / Medium / Low]
- Labels: [e.g. "Meetup" or "Meetup, Partnerships"]
- Initiatives: [e.g. "2026 Growth and GTM" — optional, can leave blank]

---

Follow this exact template:

**1. Create the project** with:
- Name format: `Event YYYY.MM.DD - [Event Name] in [City]`
- Team: GTM
- Icon: Pizza 🍕
- Color: #f2c94c
- Status: Done
- Target date: the event date above
- Labels, lead, priority, and initiatives as specified

**2. Create the following issues** in the GTM team, all with label "Event", all linked to the new project. Create them in this order so parent issues exist before their children:

Add one of these linear labels depending on the type:
Meetup
Conference
Webinar

Also add the partnership label if we worked with another company

Once done, share the Linear project URL.
